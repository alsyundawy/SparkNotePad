## 1. Ringkasan Eksekutif (Bahasa Indonesia): Rilis v1.3.9

SparkNotePad v1.3.9 menghadirkan pembaruan mesin inti resmi Scintilla 5.6.9 dan Lexilla 5.5.5, menyelesaikan kerentanan algoritmik kritis pada ekspresi reguler (regex), memperkenalkan preferensi bahasa default yang dapat dikonfigurasi pengguna untuk dokumen baru, memperluas penyorotan sintaksis front-matter Markdown, dan lulus verifikasi statis serta tinjauan kode 14 pilar secara menyeluruh:

1. Integrasi Mesin Resmi Scintilla 5.6.9:
   - Pemulihan rendering warna penuh untuk gambar XPM.
   - Akselerasi kueri posisi awal baris dengan melewati kalkulasi tata letak baris yang berulang.
   - Perluasan kapasitas buffer lexeme dari 30 menjadi 40 byte untuk identifier dan simbol query besar.
   - Paritas penuh pemetaan kategori karakter Unicode 17 dan konversi huruf besar/kecil.
   - Penyelesaian crash pada change history undo saat operasi penghapusan massal.

2. Integrasi Mesin Resmi Lexilla 5.5.5 & Front-Matter Markdown:
   - Implementasi 3 definisi gaya Lexilla 5.5.5 baru di `src/languages/markdown.lua` untuk metadata YAML, TOML, dan JSON:
     - `SCE_MARKDOWN_FRONT_MARK` (ID 22): Pembatas metadata (`---`, `+++`, `{}`).
     - `SCE_MARKDOWN_FRONT` (ID 23): Isi data dan nilai properti front-matter.
     - `SCE_MARKDOWN_FRONT_KEY` (ID 24): Kunci atribut dan properti front-matter.
   - Mitigasi kerentanan keamanan memori (out-of-bounds write CWE-787 dan read CWE-125) pada lexer DMIS, Perl, Raku, Ruby, TCMD, TeX, Visual Prolog, dan X12.
   - Peningkatan penanganan sintaksis HTML/JavaScript, PHP, dan SQL.

3. Fitur Pilihan dari NotepadNext:
   - Perbaikan infinite-loop replace-all pada regex dengan panjang nol (CWE-835 / DoS).
   - Penonaktifan otomatis pencarian mundur saat regex aktif pada dialog Cari & Ganti.
   - Pengaturan Bahasa Bawaan Dokumen Baru (Preferensi > Penyunting).

4. Kualitas Kode Tanpa Cacat & Verifikasi 14-Pilar:
   - Lulus semua linter: `cppcheck`, `clang-tidy`, `clangd`, SonarLint.
   - 100% kelulusan unit test (51/51 pengujian di 11 test suite).
   - Pembuatan dan verifikasi integritas paket lokal macOS DMG (`SparkNotePad-v1.3.9-x64.dmg`).

## 1. Executive Summary (English): Release v1.3.9

SparkNotePad v1.3.9 brings official upstream updates for the core Scintilla and Lexilla editing engines, addresses security and algorithmic issues in search and replace, enriches syntax highlighting for Markdown front-matter, adds user-configurable default language preferences for new documents, and passes complete 14-pillar code review:

1. Official Upstream Scintilla 5.6.9 Integration:
   - Restores full-color rendering for XPM images.
   - Skips unnecessary line layout calculations during line-start position queries for accelerated scrolling and navigation.
   - Increases cached lexeme buffer capacity from 30 to 40 bytes to optimize large symbols and query identifiers.
   - Full Unicode 17 standard character category tables and case conversion support.
   - Resolves change history undo crashes during bulk deletion operations.

2. Official Upstream Lexilla 5.5.5 Integration & Markdown Front-Matter:
   - Introduces 3 new Lexilla 5.5.5 style IDs in `src/languages/markdown.lua` for YAML, TOML, and JSON front-matter:
     - `SCE_MARKDOWN_FRONT_MARK` (ID 22): Delimiters (`---`, `+++`, `{}`).
     - `SCE_MARKDOWN_FRONT` (ID 23): Front-matter body and value payload.
     - `SCE_MARKDOWN_FRONT_KEY` (ID 24): Front-matter attribute keys.
   - Mitigates memory safety issues including out-of-bounds writes (CWE-787) and reads (CWE-125) in Lexilla lexers (DMIS, Perl, Raku, Ruby, TCMD, TeX, Visual Prolog, X12).
   - Enhances HTML/JavaScript, PHP, and SQL lexer syntax handling.

3. Selective Features from NotepadNext:
   - Fixed infinite loop in replace-all with zero-length regular expressions (CWE-835 / DoS).
   - Search & replace dialog automatically disables backwards direction searching when regex is active.
   - Configurable Default Language preference for new documents (Preferences > Editor).

4. Zero-Defect Quality & 14-Pillar Verification:
   - Passes all linters: `cppcheck`, `clang-tidy`, `clangd`, SonarLint.
   - 100% unit test success rate across 51 test cases in 11 test suites.
   - Built and verified local macOS DMG (`SparkNotePad-v1.3.9-x64.dmg`).
