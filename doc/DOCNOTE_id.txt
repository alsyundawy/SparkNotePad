## 1. Ringkasan Eksekutif: Perubahan pada v1.4.7

SparkNotePad v1.4.7 menghadirkan pembaruan mesin inti, mobilitas ruang kerja lintas platform, diagnostik skrip POSIX, keandalan deteksi enkodik berkas besar, peningkatan ergonomi navigasi, serta penguatan keamanan menyeluruh terhadap CVE 2025–2026:

1. Pembaruan Mesin Inti ke Scintilla 5.6.9 & Lexilla 5.5.5:
   - Sinkronisasi Scintilla ke v5.6.9 (kategori karakter Unicode 17, tembolok leksem 40-byte, optimasi layout awal baris yang mempercepat rendering, perbaikan crash riwayat undo, dan pemulihan warna autokompleksi XPM).
   - Sinkronisasi Lexilla ke v5.5.5 (pewarnaan front-matter Markdown YAML/TOML/JSON [#59], nested template literal HTML/JS [#290], regex '/' dalam karakter kelas [#377], identifier JS non-ASCII [#371], pewarnaan $$variabel PHP [#2208], dan 12 perbaikan keamanan memori/OOB [#388]).
   - Penerapan 4 patch resmi Lua 5.5.1 (proteksi pergeseran negatif luaO_applyparam, perbaikan for-loop NaN lvm.c, pencegahan folding -0.0 lcode.c, dan preservasi pesan error unwind lcorolib.c).

2. Transfer Sistem & Berkas Bundel Ruang Kerja Portabel (SparkTransferManager & TransferBundleDialog):
   - Fitur Berkas -> Transfer Sistem -> Ekspor / Impor Bundel Ruang Kerja (.sparkbundle) untuk migrasi preferensi, tema kustom (QSS), makro, sesi, dan skrip Lua/Python antar-macOS, FreeBSD, dan Linux.
   - Dilindungi pertahanan Zip-Slip (CVE-2026-57233), penolakan path traversal (CVE-2026-52886), verifikasi integritas in-memory HMAC SHA-256 (CVE-2026-52885), dan enkripsi opsional AES-256-CBC.

3. Inspektur Shell POSIX & Utilitas Touch (PosixFileInspector):
   - Deteksi dialek shebang: Bash, Zsh, Dash, Ksh, POSIX sh, Python, Lua, dan skrip rc.d FreeBSD.
   - Format izin oktal (0755/0600) dan simbolik (rwxr-xr-x/rw-------).
   - Badge FieldPosixPerms pada EditorInfoStatusBar dengan tombol toggle executable (chmod +x) sekali klik.
   - Submenu Izin Berkas pada menu Berkas: "Beralih Bit Eksekutabel (chmod +x)" dan "Terapkan Mode Pribadi Pemilik Saja (chmod 0600)".
   - Utilitas touch berkas presisi tinggi via POSIX utimes.

4. Detektor Enkodik 3-Titik Tanpa State & Proteksi Penyimpanan Berkas Besar Atomik:
   - Pengambilan sampel 3 titik (header 16KB, tengah 16KB, akhir 16KB) untuk keandalan deteksi charset berkas besar via uchardet.
   - Dukungan eksplisit BOM UTF-32 LE/BE (\xFF\xFE\x00\x00 dan \x00\x00\xFE\xFF).
   - Pengerasan ScintillaNext::writeToDisk dengan penyimpanan atomik menggunakan berkas temporer privat sibling (.filename.sparktmp), izin 0600, fsync(), preservasi mode izin asli, dan operasi POSIX rename() atomik.

5. Dialog Go To Multi-Mode & Pratinjau Ganti Nama Aman Pohon Proyek:
   - Menggantikan input modal lama dengan GotoDialog multi-mode yang mendukung Baris:Kolom Visual, Offset Karakter (Line:-Col), dan Offset Byte Dokumen secara real-time.
   - Dialog ganti nama aman di FolderAsWorkspaceDock dengan mitigasi path traversal, deteksi tabrakan nama, dan simulasi dry-run sebelum berkas diubah di disk.

6. Penguatan Keamanan Menyeluruh CVE 2025–2026:
   - Verifikasi pengujian otomatis terhadap CVE-2026-42214, CVE-2026-48778, CVE-2026-52885, CVE-2026-52886, CVE-2026-57233, CVE-2026-54758, dan CVE-2026-77605.

7. Perbaikan Warna Teks Dialog Tentang & Pratinjau Markdown:
   - Memperbaiki bug indeks placeholder %2 pada tab Kredit AboutDialog yang sebelumnya merender teks mentah #0550ae sebagai judul heading.
   - Menghapus warna heksadesimal statis #0550ae pada formula math Markdown Preview Enhancer agar mewarisi warna teks tema alami.

8. Remediasi Kualitas Kode 14 Pilar & Kepatuhan SonarLint/Clang-Tidy:
   - Memperbaiki kurung kurawal statement tunggal, visibilitas virtual override, dan semantik pemindahan (move semantics) di EditorInfoStatusBar, QuickFindWidget, StatusLabel, dan FocusWatcher (0 linter errors).

9. Standar Pengemasan DMG macOS Ringan (Standar 30MB–40MB):
   - Mengemas dan memverifikasi build/SparkNotePad-v1.4.7-x64.dmg (40M, 40,652,861 bytes) dengan gambar latar custom, preset layout .DS_Store (680x440), dan checksum CRC32 tervalidasi.

## 2. Ringkasan Arsip: Rilis v1.4.6

SparkNotePad v1.4.6 menghadirkan ekspansi kustomisasi visual bilah alat, peningkatan kenyamanan editor, dan standar pengemasan berkualitas tinggi dari versi 1.4.5:

1. Ekspansi Paket Ikon Toolbar (Total 69 Koleksi Bawaan):
   - Ditambahkan 41 paket ikon baru multi-resolusi (16x16, 20x20, 24x24, 32x32, 48x48, 64x64).
   - Invarian Toolbar Gelap Permanen (`#21252b`) di seluruh mode dan tema.

2. Fitur Baru Menu Konteks Editor:
   - Menu "Tempel & Cocokkan Format" (Paste & Match Style) dan "Cari di Google".
   - Perampingan konversi huruf kapital/kecil langsung.

3. Penambahan Opsi Preferensi Umum:
   - Opsi Aktifkan / Nonaktifkan Deteksi Enkodik Otomatis dan Konfirmasi Simpan Semua.

4. Standar Pengemasan DMG macOS Ringan:
   - Pengemasan DMG presisi 30MB–40MB dengan aset presentasi lengkap.
