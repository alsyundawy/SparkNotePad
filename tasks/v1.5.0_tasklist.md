## 3. Protokol & Checklist Review Kode 14 Pilar Komprehensif Seluruh Berkas Repositori `SparkNotePad`

Setiap berkas dalam repositori ini (`src/*`, `src/*/*`, `scripts/*`, `deploy/*`, `tests/*`, dsb.) wajib diperiksa menggunakan checklist 14 pilar berikut:

1. **Bug Review**:
   - [x] Pointer validity: Setiap dereferensi pointerScintilla, QWidget, atau buffer data dipastikan non-null (`if (!ptr) return;`).
   - [x] Boundary check: Tidak ada operasi akses indeks array atau string di luar batas (`index >= size`).
   - [x] Return value verification: Nilai kembalian API POSIX, OpenSSL, dan Qt selalu diperiksa.
   - [x] Signal/Slot integrity: Seluruh koneksi `connect()` menggunakan pointer-to-member syntax modern dengan siklus hidup objek terkelola.

2. **Syntax Review**:
   - [x] Standar ISO C++20: Menggunakan `std::span`, `std::string_view`, `constexpr`, dan type aliases modern.
   - [x] Clang 23 Clean: Nol warning atau error saat dikompilasi dengan `-Wall -Wextra -Wpedantic`.
   - [x] Bash 5.3 ShellCheck Clean: Seluruh skrip shell lolos `shellcheck -s bash` tanpa unquoted variables.
   - [x] Markdownlint Clean: Seluruh berkas `.md` lolos `markdownlint-cli2` dengan nol issues.

3. **Runtime Review**:
   - [x] Exception Safety: Operasi alokasi memori besar atau parsing file aman dari crash dan exception tak tertangani.
   - [x] UI Responsiveness: Operasi I/O berat (live tail, SFTP, enkripsi berkas besar) dijalankan di background thread atau dengan debouncing timer.
   - [x] Signal handling: Menangani event terminasi jendela atau crash recovery secara anggun.

4. **Logic Review**:
   - [x] State consistency: Sinkronisasi status checked pada aksi menu, toolbar, dan status bar selalu konsisten.
   - [x] Correctness: Perhitungan waktu ISO/Epoch, enkripsi/dekripsi, konversi encoding, dan formatting teks menghasilkan keluaran yang benar dan dapat dibuktikan.
   - [x] Edge cases handling: Buffer kosong, string hanya spasi, atau file 0-byte ditangani secara aman tanpa kegagalan.

5. **Memory & Resource Review**:
   - [x] Zero Memory Leaks: Seluruh objek QObject memiliki parent hierarchy yang jelas; alokasi non-QObject menggunakan `std::unique_ptr` atau RAII.
   - [x] Secure Zeroization: Buffer passphrase dan kunci enkripsi dibersihkan segera dengan `OPENSSL_cleanse` / `explicit_bzero`.
   - [x] Lightweight Resource Usage: Memory footprint idle < 35MB; aset grafis dimuat secara lazy-loading.
   - [x] Plafon DMG Ketat: Ukuran paket DMG macOS berada dalam rentang 30MB s/d 40MB.

6. **Dead Code Review**:
   - [x] Eliminasi Unused Code: Tidak ada fungsi helper, variabel lokal, atau impor header usang yang tidak pernah dipanggil.
   - [x] Penghapusan `openInBrowser`: Seluruh fungsi, tombol, dan slot yang terkait dengan pembukaan browser web eksternal telah dihapus tuntas.

7. **Duplicate Code Review**:
   - [x] DRY Principle: Logika sanitasi HTML, perhitungan hash, manipulasi string, dan konversi warna difaktorkan ke kelas utility bersama (`DeveloperToolsEngine`, `MimeToolsEngine`, `ConverterToolsEngine`, `ThemeManager`).

8. **Circular Dependency Review**:
   - [x] Clean Architecture: Forward declarations digunakan secara ekstensif pada file header `.h`.
   - [x] Layer Decoupling: Tidak ada dependensi melingkar antara `MainWindow`, `ScintillaNext`, `DockWidget`, dan `Manager` classes.
