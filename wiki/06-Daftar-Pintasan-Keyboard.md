# Referensi Cepat Pintasan Keyboard

SparkNotePad dirancang untuk memberikan produktivitas maksimal berbasis keyboard. Hampir setiap tindakan utama—mulai dari pencarian berkas cepat, pembukaan peluncur perintah, pemindahan jendela antar-monitor, hingga operasi kriptografi—dapat dijalankan langsung tanpa perlu menyentuh mouse.

---

## 1. Navigasi Global & Peluncur Perintah

SparkNotePad memiliki arsitektur palet cepat dua mode yang terinspirasi oleh lingkungan IDE modern:

| Tindakan                                | macOS Shortcut               | Linux / Windows Shortcut      | Cakupan & Fungsi                                        |
| :-------------------------------------- | :--------------------------- | :---------------------------- | :------------------------------------------------------ |
| **Buka Cepat (Omnibar)**                | `Cmd+P` / `Ctrl+Alt+O`       | `Ctrl+P` / `Ctrl+Alt+O`       | Pencarian berkas samar (_fuzzy_) real-time dalam proyek |
| **Peluncur Perintah (Command Palette)** | `Cmd+Shift+P` / `Ctrl+Alt+I` | `Ctrl+Shift+P` / `Ctrl+Alt+I` | Akses 100+ aksi menu, konverter, dan pemformat kode     |
| **Fokuskan ke Editor Teks**             | `Ctrl+Alt+E`                 | `Ctrl+Alt+E`                  | Kembalikan fokus keyboard ke kanvas editor seketika     |
| **Bantuan Pintasan & Aksesibilitas**    | `Shift+F1`                   | `Shift+F1` / `F1`             | Buka dialog interaktif referensi seluruh tombol pintas  |
| **Buku Panduan & Dokumentasi Wiki**     | `F1`                         | `Ctrl+F1`                     | Buka panduan pengguna lokal atau Wiki resmi GitHub      |

## 2. Manajemen Berkas & Dokumen

| Tindakan                     | macOS Shortcut    | Linux / Windows Shortcut | Deskripsi                                                      |
| :--------------------------- | :---------------- | :----------------------- | :------------------------------------------------------------- |
| **Dokumen Baru**             | `Cmd+N`           | `Ctrl+N`                 | Membuat dokumen kosong baru pada tab baru                      |
| **Buka Dokumen**             | `Cmd+O`           | `Ctrl+O`                 | Membuka dialog pemilih berkas                                  |
| **Simpan Dokumen**           | `Cmd+S`           | `Ctrl+S`                 | Menyimpan berkas secara aman ke disk                           |
| **Simpan Sebagai (Save As)** | `Cmd+Shift+S`     | `Ctrl+Shift+S`           | Menyimpan salinan berkas dengan nama/lokasi baru               |
| **Simpan Semua Dokumen**     | `Cmd+Alt+S`       | `Ctrl+Alt+S`             | Menyimpan seluruh tab dokumen yang termodifikasi               |
| **Tutup Tab Aktif**          | `Cmd+W`           | `Ctrl+W`                 | Menutup tab aktif dengan peringatan simpan jika diubah         |
| **Tutup Semua Tab**          | `Cmd+Shift+W`     | `Ctrl+Shift+W`           | Menutup semua tab terbuka secara bersamaan                     |
| **Tab Berikutnya**           | `Ctrl+Tab`        | `Ctrl+Tab`               | Berpindah maju ke tab dokumen berikutnya                       |
| **Tab Sebelumnya**           | `Ctrl+Shift+Tab`  | `Ctrl+Shift+Tab`         | Berpindah mundur ke tab dokumen sebelumnya                     |
| **Cetak Dokumen**            | `Cmd+Alt+Shift+P` | `Ctrl+Alt+Shift+P`       | Mencetak dokumen dengan penyesuaian margin dan warna sintaksis |
| **Mulai Ulang Aplikasi**     | `Cmd+Alt+R`       | `Ctrl+Alt+R`             | Me-restart aplikasi dengan aman mempertahankan sesi aktif      |

| Tindakan                         | macOS Shortcut          | Linux / Windows Shortcut  | Deskripsi                                               |

| **Urungkan (Undo)**              | `Cmd+Z`                 | `Ctrl+Z`                  | Membatalkan perubahan penyuntingan terakhir             |

| **Tempel (Paste)**               | `Cmd+V`                 | `Ctrl+V`                  | Menempelkan teks dari papan klip pada posisi kursor     |
| **Pilih Semua (Select All)**     | `Cmd+A`                 | `Ctrl+A`                  | Memilih seluruh teks di dalam dokumen                   |
| **Duplikasi Baris / Seleksi**    | `Cmd+D`                 | `Ctrl+D`                  | Menduplikasi baris aktif atau teks yang disorot         |
| **Hapus Baris**                  | `Cmd+Shift+K`           | `Ctrl+Shift+K`            | Menghapus baris aktif tanpa menyalin ke clipboard       |
| **Komentar Sebaris (Toggle)**    | `Cmd+/`                 | `Ctrl+/`                  | Memberi atau menghapus tanda komentar baris (`//`, `#`) |
| **Komentar Blok (Toggle)**       | `Cmd+Alt+/`             | `Ctrl+Shift+/`            | Membungkus seleksi dalam komentar blok (`/* */`)        |
| **Gabungkan Baris (Join Lines)** | `Cmd+J`                 | `Ctrl+J`                  | Menggabungkan baris-baris terpilih menjadi satu baris   |
| **Tambah Indentasi**             | `Tab`                   | `Tab`                     | Menggeser blok teks ke kanan sesuai ukuran tab          |
| **Kurangi Indentasi**            | `Shift+Tab`             | `Shift+Tab`               | Menggeser blok teks ke kiri sesuai ukuran tab           |

| **Pratinjau Aman Markdown**     | `Cmd+Shift+M`  | `Ctrl+Shift+M`           | Membuka pratinjau rendering HTML Markdown berdampingan         |
| **Ganti Tema Gelap / Terang**   | `Cmd+Alt+T`    | `Ctrl+Alt+T`             | Berganti cepat antara tema gelap dan terang favorit            |
