# Catatan Perubahan (Changelog)

Semua perubahan penting pada **SparkNotePad** didokumentasikan di berkas ini.

Format disusun berdasarkan panduan [Keep a Changelog](https://keepachangelog.com/id/1.1.0/),
dan proyek ini sepenuhnya mematuhi [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.5.0] - 2026-11-19

### 🌟 Rilis: Rangkaian Fitur Lengkap Developer Tools (JSON/XML/HTML/CSS/JS, Enkripsi, JWT, Radiks), Restrukturisasi Menu, Pratinjau Markdown GitHub Primer & Peningkatan Tampilan

SparkNotePad v1.5.0 menghadirkan suite Developer Tools lengkap terpadu yang diporting dari NotepadMac, ergonomi menu yang direstrukturisasi, Pratinjau Langsung Markdown Aman GitHub Primer, dan peningkatan kontrol tampilan:

#### 🆕 Ditambahkan (Added)

- **Rangkaian Lengkap Developer Tools (`DeveloperToolsEngine` & `DeveloperToolsDialog`)**:
  - Dialog interaktif multi-tab Developer Tools Hub (`Ctrl+Alt+T` / `Ctrl+Cmd+T`) dengan 5 tab fungsional:
    - **Hash Tools**: 11 algoritma hash kriptografis (MD5, SHA-1, SHA-224, SHA-256, SHA-384, SHA-512, SHA3-224, SHA3-256, SHA3-384, SHA3-512, Keccak-256), hashing integritas berkas, serta perbandingan checksum berdampingan dengan indikator kecocokan visual.
    - **MIME Tools**: Enkode/dekode Base64 baris demi baris, Quoted-Printable (RFC 2045), URL encode/decode, dan HTML entities encode/decode.
    - **Converter Tools**: Konverter basis Radiks (Biner, Oktal, Desimal, Heksadesimal), konverter ASCII <-> Heksadesimal dengan pemisah kustom, serta konversi format huruf (Title Case, Invert Case, Sentence Case).
    - **Encryption Tools**: Proteksi Enkripsi Dokumen HTML dengan 3 mode operasional:
      1. Injeksi unescape JavaScript.
      2. Enkode Base64 `atob()`.
      3. Enkripsi standar militer Password AES-256-GCM dengan harness runtime dekripsi CryptoJS tertanam.
      - Pengukur kekuatan kata sandi dan entropi ala zxcvbn secara real-time.
    - **Developer Tools**: Pemformat (pretty-print) dan pemadat (minify) untuk JSON, XML, HTML, CSS, dan JavaScript; Inspektur Token RFC 7519 JWT dengan ekstraksi header/payload serta validasi timestamp kedaluwarsa; pembuat UUID v4; dan konverter dua arah Unix Epoch / ISO-8601.
  - Perombakan total tata letak dan ergonomi dialog `DeveloperToolsDialog`: standarisasi tinggi tombol 32px, tipografi modern, pemisahan kontrol enkripsi html untuk mencegah desak-desakan kolom, grid 5-kolom seimbang untuk formatter/minifier, serta integrasi font sistem native macOS.
  - Penambahan suite unit test di `tests/test_developer_tools_engine.h` yang memverifikasi seluruh 10 fitur developer tools.
- **Pratinjau Langsung Markdown Aman GitHub Primer Sempurna (`mjbvz/vscode-github-markdown-preview-style`)**:
  - Rekayasa ulang engine perender pratinjau yang sepenuhnya selaras dengan token visual GitHub Markdown Preview.
  - Pembersihan seluruh artefak internal Qt rich text (`-qt-block-indent`, margin bawaan paragraf) dan perbaikan pewarisan warna CSS ke seluruh elemen anak (`p`, `li`, `td`, `th`, `span`, `div`), melenyapkan tuntas masalah teks putih di atas latar putih pada tema terang (`GITHUB`, dll.).
  - Kontainer blok kode modern GitHub Primer dengan background gelap `#0d1117`, pill header berkas (`#161b22`, border `#30363d`), lencana pill rounded (`#21262d`), tombol salin bersih (`[ ❐ ]` / `[ ⎘ Copy ]`), dan tipografi monospace murni.
  - Jaminan eksekusi skrip bash 100% valid saat disalin: normalisasi sintaks strict mode multiline `IFS=$'[\r\n\t ]*'` menjadi `IFS=$'\n\t'`, konversi tanda kutip cerdas ke ASCII, pemaksaan Unix LF murni, pembersihan spasi di akhir baris, dan eliminasi label salin redundan (`[📋 Salin Perintah / Copy Code Block]`, dll.), menjamin perintah bash yang disalin dapat langsung dijalankan di terminal tanpa kesalahan sintaks.
  - Integrasi penormal SVG otomatis untuk Shields.io (mengganti `font-size="100"` menjadi `10`, menghapus `transform="scale(.1)"`, menskalakan ulang textLength, dan menerapkan batas klip kanvas), melenyapkan masalah lencana bertumpuk dan meluap.
  - Pembersihan atribut `width="100%"` yang tidak didukung Qt (mencegah gambar menciut ke -2px), pembatasan lebar gambar ke batas viewport (maksimal 850px), serta relayout asynchronous ter-debounce (`performDeferredRelayout()`) setelah gambar remote selesai diunduh untuk menjaga ketinggian dokumen yang presisi.
  - Sinkronisasi Scroll Presisi Sub-Pixel Anchor-Bracketed: menggantikan rasio baris linear dengan interpolasi sub-pixel berbasis kurung anchor (`findAnchorBracket`), melenyapkan drift scroll dan lagging pratinjau sehingga editor dan preview sejajar sempurna secara real-time.
  - Ketahanan dokumen masif: divalidasi pada dokumen teknis raksasa (seperti panduan Zimbra 10.1.21 dengan 6.000+ baris) tanpa lonjakan memori, jeda, atau batasan perenderan.
  - Melenyapkan jeda 3,1 detik pembangunan database font macOS pada setiap perenderan dengan mengganti font tidak terdaftar `-apple-system` menjadi `'Helvetica Neue', Helvetica, Arial, sans-serif` di 30 tema Markdown.
  - Dukungan native GitHub Alert Callouts (`[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`) dengan garis tepi dan lencana resmi.
  - Penghapusan total tombol dan fungsi "Open in Default Browser" di seluruh dock dan widget pratinjau demi keamanan maksimal dan operasi mandiri tanpa bloatware.
- **Restrukturisasi Menu Tingkat Atas**:
  - Penambahan menu tingkat atas **Format** yang mengelompokkan konversi set karakter / enkoding (`ui->menuEncodings`) dan konversi pemisah baris (`ui->menuEOLConversion`).
  - Relokasi menu **Run & External Execution** dari bilah menu utama ke dalam menu `Tools -> Run & External Execution` (`Ctrl+Alt+R` / `F5`).
  - Penambahan submenu khusus **Developer Tools** di dalam `Tools` dengan aksi langsung untuk formatter, minifier, encoder, dan dialog Developer Tools Hub (`Ctrl+Alt+T`).
- **Peningkatan Sakelar Tampilan (View & Navigation Toggles)**:
  - Penambahan sakelar di menu `View` untuk mengaktifkan/menonaktifkan Nomor Baris, Pelipatan Kode, Garis Panduan Indentasi, Sorotan Baris Kursor, Mode Hanya-Baca (Read-Only), serta Pembesaran (Zoom In / Out / Reset).
- **Perbaikan & Modernisasi Sistem Pewarnaan Tab (`TabColorManager` & `DockedEditor`)**:
  - Rekayasa ulang menyeluruh gaya tab: mengganti styling border lokal yang rapuh dengan stylesheet ADS lengkap yang mempertahankan sudut melengkung (`6px`), gradien latar tema, serta status tab aktif/tidak aktif dan efek tombol tutup.
  - Garis aksen atas 3px (`border-top: 3px solid <warna>`) dengan tint latar belakang lembut (28% tab aktif, 14% tab tidak aktif).
  - Dukungan warna untuk berkas baru tanpa judul (`new 1`, `new 2`) dengan migrasi persistensi otomatis saat berkas disimpan atau diubah namanya.
  - Penambahan pemilih warna interaktif `Warna Kustom...` (`QColorDialog`) dan aksi `Hapus Warna Tab` berikon visual.
  - Sinkronisasi dinamis terhadap pergantian tema Terang/Gelap tanpa kehilangan konfigurasi warna tab aktif.
- **Pemisah Pemisah Menu Konteks Editor**:
  - Penambahan pemisah visual khusus antara `Select All` dan `UPPER CASE` / `lowercase` pada menu klik kanan editor Scintilla, memisahkan perintah seleksi global secara ergonomis dari operasi transformasi teks.
- **Tata Letak & Tooltip Menyeluruh Dialog Alat Pengembang (Developer Tools Hub)**:
  - Standardisasi ukuran tombol yang kompak (`font-size: 10px`, `padding: 2px 6px`, `min-height: 24px`, font dasar dialog `9.5pt`) melenyapkan pemotongan teks tombol di seluruh bahasa dan resolusi layar.
  - Penghapusan pembatasan lebar kaku dan pemecahan baris kontrol utilitas menjadi dua baris berimbang (`rowJwt` dan `rowUuid`).
  - Penambahan tooltip interaktif informatif (`setToolTip(...)`) pada 100% kontrol dialog tanpa terkecuali (tombol, tab, kolom teks, checkbox, spinbox, dan combobox).
- **Penataan Jarak Vertikal & Line-Height Baris Lencana Shields.io**:
  - Penegakan `line-height: 34px` dan margin proporsional pada paragraf yang memuat lencana/badge Shields.io (seperti pada README SparkleSFTP), melenyapkan tuntas pemotongan vertikal dan tumpang tindih lencana.
- **Lokalisasi Penuh Bahasa Indonesia & Inggris (i18n)**:
  - Cakupan terjemahan 100% tuntas untuk Bahasa Indonesia (`SparkNotePad_id.ts`, 2.347 entri) dan Bahasa Inggris (`SparkNotePad_en.ts`, 2.376 entri) dengan 0 entri unfinished, terkompilasi langsung ke pustaka biner `.qm`.
- **Pembaruan Kredit, Pintasan & Terjemahan**:
  - Pembaruan tab Kredit & Pintasan pada dialog `AboutDialog` dengan hotkey dan atribusi baru.
  - Sinkronisasi katalog terjemahan `i18n` (`SparkNotePad_id.ts`, `SparkNotePad_en.ts`) dan kompilasi berkas biner `.qm`.

## [1.4.7] - 2026-11-14

### 🌟 Rilis: Peningkatan Engine Inti (Scintilla 5.6.9, Lexilla 5.5.5, Lua 5.5.1 Ter-patch), Transfer Sistem (.sparkbundle), Inspektur Berkas POSIX, Deteksi Enkoding 3 Titik & Penguatan Keamanan CVE 2025–2026

SparkNotePad v1.4.7 menghadirkan peningkatan engine inti, mobilitas ruang kerja lintas platform, diagnostik skrip POSIX, ketahanan enkoding berkas besar, ergonomi navigasi, dan penguatan keamanan CVE komprehensif:

#### 🆕 Ditambahkan (Added)

- **Peningkatan Engine Inti ke Scintilla 5.6.9 & Lexilla 5.5.5**:
  - Sinkronisasi Scintilla ke versi **5.6.9** (kategori karakter Unicode 17, cache leksem 40-byte, bypass kalkulasi tata letak awal baris, perbaikan crash undo riwayat perubahan, dan pemulihan warna gambar XPM).
  - Sinkronisasi Lexilla ke versi **5.5.5** (pengenalan front-matter Markdown YAML/TOML/JSON, template literal bersarang HTML/JS, perbaikan 12 isu keamanan memori dan crash preprocessor C++).
  - Penerapan 4 patch resmi Lua pasca-5.5.1 pada embedded Lua 5.5.1.
- **Transfer Sistem & Bundel Ruang Kerja Portabel (`SparkTransferManager`)**:
  - Fitur **Berkas → Transfer Sistem → Ekspor / Impor Bundel Ruang Kerja (`.sparkbundle`)** untuk migrasi preferensi, tema kustom, makro, sesi, dan skrip Lua/Python.
  - Penguatan terhadap Zip-Slip traversal (`CVE-2026-57233`), validasi integritas HMAC-SHA256 dalam memori (`CVE-2026-52885`), dan opsi enkripsi AES-256-CBC.
- **Inspektur Shell POSIX & Utilitas Touch (`PosixFileInspector`)**:
  - Deteksi dialek shebang untuk Bash, Zsh, Dash, Ksh, POSIX sh, Python, Lua, dan skrip `rc.d` FreeBSD.
  - Pemformat izin oktal (`0755`/`0600`) dan simbolik (`rwxr-xr-x`/`rw-------`).
  - Lencana status bar `FieldPosixPerms` dengan sakelar bit eksekusi sekali klik (`chmod +x`).
- **Deteksi Enkoding 3-Titik & Penyimpanan Berkas Atomik Aman**:
  - Pengambilan sampel 3 titik (header 16KB, midpoint 16KB, tail 16KB) untuk deteksi akurat encoding file besar via `uchardet`.
  - Dukungan BOM UTF-32 LE/BE eksplisit dan penyimpanan file atomik via file sementara bertanda `0600` dan `fsync()`.
- **Dialog Goto Multi-Mode & Pratinjau Ganti Nama Aman Folder As Workspace**:
  - Penggantian dialog input lawas dengan `GotoDialog` yang mendukung Baris:Kolom Visual, Offset Karakter, dan Offset Byte Dokumen.
  - Dialog ganti nama berkas/folder interaktif dengan mitigasi path traversal dan pratinjau dry-run.

- **Perombakan Total Engine & Live Preview Markdown**:

  - Penyelarasan fungsi copyHtml(), openInBrowser(), dan DocumentExportManager::markdownToHtml agar hasil ekspor dan salinan HTML memuat seluruh rumus math, diagram mermaid, daftar tugas, catatan kaki, dan callout secara utuh.
  - Perbaikan database kompilasi (compile_commands.json) dengan sinkronisasi 685 header, menuntaskan 945+ pesan error IDE linter dan peringatan SonarLint.

- **Pembersihan Menu Konteks**:
  - Menghapus opsi Run dan Bash encode/decode dari menu klik kanan editor agar lebih ringkas dan fokus.
- **Modernisasi Tampilan Tab Split & Arsitektur Zero Theme Clash**:
  - Menghilangkan gradien gelap metalik dan batas jingga/peach peninggalan lawas dengan mengaktifkan cds::CDockManager::DisableStylesheet, true.
  - Styling tab split sepenuhnya dinamis mengikuti palet tema aktif melalui ThemeManager.
- **UX Auto-Completion & Harmonisasi Tema**:
  - Menonaktifkan auto-completion secara default (autoCompletion = false) untuk mencegah popup kandidat yang mengganggu.
  - Mengganti penamaan tema bawaan menjadi sparkNotepad ("SparkNotepad Default") dengan kompatibilitas mundur.
- **Engine Pembaruan Multi-Build updates.json & Force-Update Komprehensif**:
  - Memperbarui updates.json ke v1.4.6 dengan dukungan matriks rilis lengkap dan kebijakan pembaruan wajib.
- **Audit Kualitas Kode 14 Pilar & Audit Linter**:
  - 100% lulus bersih pada cppcheck (171 berkas, 0 kesalahan), clangd, clang-tidy, dan ctest.
  - Penyesuaian aturan SonarLint pada parameter lambda dan pointer-to-const.
