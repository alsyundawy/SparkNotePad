# Catatan Perubahan (Changelog)

Semua perubahan penting pada **SparkNotePad** didokumentasikan di berkas ini.

Format disusun berdasarkan panduan [Keep a Changelog](https://keepachangelog.com/id/1.1.0/),
dan proyek ini sepenuhnya mematuhi [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.4.7] - 2026-11-14

### 🌟 Rilis: Pembaruan Inti Mesin (Scintilla 5.6.9, Lexilla 5.5.5, Patch Lua 5.5.1), Transfer Sistem (.sparkbundle), Inspektur Berkas POSIX, Deteksi Enkodik 3-Titik & Audit Keamanan CVE 2025–2026

SparkNotePad v1.4.7 menghadirkan pembaruan mesin inti, mobilitas ruang kerja lintas platform, diagnostik skrip POSIX, keandalan deteksi enkodik berkas besar, peningkatan ergonomi navigasi, serta penguatan keamanan menyeluruh terhadap CVE 2025–2026:

#### 🆕 Ditambahkan (Added)

- **Pembaruan Mesin Inti ke Scintilla 5.6.9 & Lexilla 5.5.5**:
  - Sinkronisasi Scintilla ke **v5.6.9** (kategori karakter Unicode 17, tembolok leksem 40-byte, optimasi layout awal baris yang mempercepat rendering, perbaikan crash riwayat undo, dan pemulihan warna autokompleksi XPM).
  - Sinkronisasi Lexilla ke **v5.5.5** (pewarnaan front-matter Markdown YAML/TOML/JSON [#59], nested template literal HTML/JS [#290], regex `/` dalam karakter kelas [#377], identifier JS non-ASCII [#371], pewarnaan `$$variabel` PHP [#2208], akselerasi SQL q-string [#378], dan 12 perbaikan keamanan memori/OOB [#388]).
  - Penerapan 4 patch resmi Lua 5.5.1 (`luaO_applyparam` proteksi pergeseran negatif, `lvm.c` perbaikan for-loop NaN, `lcode.c` pencegahan folding -0.0, dan `lcorolib.c` preservasi pesan error unwind).
- **Transfer Sistem & Berkas Bundel Ruang Kerja Portabel (`SparkTransferManager` & `TransferBundleDialog`)**:
  - Fitur **Berkas → Transfer Sistem → Ekspor / Impor Bundel Ruang Kerja (`.sparkbundle`)** untuk migrasi preferensi, tema kustom (QSS), makro, sesi, dan skrip Lua/Python antar-macOS, FreeBSD, dan Linux.
  - Dilindungi pertahanan Zip-Slip (`CVE-2026-57233`), penolakan path traversal (`CVE-2026-52886`), verifikasi integritas in-memory HMAC SHA-256 (`CVE-2026-52885`), dan enkripsi opsional AES-256-CBC.
- **Inspektur Shell POSIX & Utilitas Touch (`PosixFileInspector`)**:
  - Deteksi dialek shebang: Bash, Zsh, Dash, Ksh, POSIX sh, Python, Lua, dan skrip `rc.d` FreeBSD.
  - Format izin oktal (`0755`/`0600`) dan simbolik (`rwxr-xr-x`/`rw-------`).
  - Badge `FieldPosixPerms` pada `EditorInfoStatusBar` dengan tombol toggle executable (`chmod +x`) sekali klik.
  - Submenu Izin Berkas pada menu Berkas: **Beralih Bit Eksekutabel (chmod +x)** dan **Terapkan Mode Pribadi Pemilik Saja (chmod 0600)**.
  - Utilitas touch berkas presisi tinggi via POSIX `utimes`.
- **Detektor Enkodik 3-Titik Tanpa State & Proteksi Penyimpanan Berkas Besar Atomik**:
  - Pengambilan sampel 3 titik (header 16KB, tengah 16KB, akhir 16KB) untuk keandalan deteksi charset berkas besar via `uchardet`.
  - Dukungan eksplisit BOM UTF-32 LE/BE (`\xFF\xFE\x00\x00` dan `\x00\x00\xFE\xFF`).
  - Pengerasan `ScintillaNext::writeToDisk` dengan penyimpanan atomik menggunakan berkas temporer privat sibling (`.filename.sparktmp`), izin `0600`, `fsync()`, preservasi mode izin asli, dan operasi POSIX `rename()` atomik.
- **Dialog Go To Multi-Mode & Pratinjau Ganti Nama Aman Pohon Proyek**:
  - Menggantikan input modal lama dengan `GotoDialog` multi-mode yang mendukung Baris:Kolom Visual, Offset Karakter (`Line:-Col`), dan Offset Byte Dokumen secara real-time.
  - Dialog ganti nama aman di `FolderAsWorkspaceDock` dengan mitigasi path traversal, deteksi tabrakan nama, dan simulasi dry-run sebelum berkas diubah di disk.
- **Perbaikan Visual & Warna Teks Kredit**:
  - Memperbaiki bug indeks placeholder `%2` pada tab Kredit `AboutDialog` yang sebelumnya merender teks heksadesimal mentah `#0550ae` sebagai judul heading.
  - Menghapus warna heksadesimal statis `#0550ae` pada formula math Markdown Preview Enhancer agar mewarisi warna teks tema alami.
- **Sinkronisasi Terjemahan & Lokalisasi**:
  - Sinkronisasi penuh katalog terjemahan bahasa Inggris (`i18n/SparkNotePad_en.ts`) dan bahasa Indonesia (`i18n/SparkNotePad_id.ts`) dengan 2.247 entri, kelengkapan 100%, dan standar EYD V / PASTI.

#### 🛡️ Penguatan Keamanan (Audit CVE 2025–2026)

- **Kekebalan CVE-2026-42214**: Mengeliminasi injeksi kode Lua arbitrer lewat ekstensi berkas dengan melewatkan seluruh parameter melalui Lua C stack (`lua_pushlstring`) serta menonaktifkan paket sistem yang tidak aman.
- **Kekebalan CVE-2026-48778, CVE-2026-48800, CVE-2026-52885**: Penegakan validasi integritas in-memory HMAC SHA-256 dan penulisan berkas disk atomik berizin `0600`.
- **Kekebalan CVE-2026-52886 & CVE-2026-57233**: Kanonikalisasi ketat pada seluruh path arsip dan sesi melalui `weakly_canonical` / `canonicalFilePath` dengan penolakan traversal Zip-Slip.
- **Kekebalan CVE-2026-54758, CVE-2026-85279, CVE-2026-86054, CVE-2026-5525**: Nol buffer stack berukuran tetap pada codebase inti; seluruh parsing string menggunakan `QString` dan `std::string` yang dibatasi.
- **Kekebalan CVE-2026-77605 & CVE-2026-25926 / CVE-2026-38972**: Resolusi path absolut untuk utilitas sistem eksternal (`/usr/bin/open`, `/usr/bin/xdg-open`), melarang eksekusi skrip sibling di direktori kerja.
- **Kekebalan CVE-2025-14575 & CVE-2026-20841**: Penegakan protokol TLS 1.2+ minimum dan whitelist ketat skema URI pratinjau Markdown.
- **Suite Pengujian Regresi Otomatis**: Menambahkan `tests/test_v147_features.h` berisi 9 kasus uji komprehensif untuk memverifikasi seluruh fitur baru dan regresi CVE.

## [1.4.6] - 2026-11-10

### 🌟 Rilis: 41 Paket Ikon Toolbar Baru (Total 69 Koleksi Bawaan), Ergonomi Menu Konteks, Opsi Preferensi Umum, Perombakan Syntax Highlighting WCAG 2.1 & Standar DMG Rilis 30MB–40MB

SparkNotePad v1.4.6 menghadirkan ekspansi kustomisasi visual bilah alat, peningkatan kenyamanan editor, dan standar pengemasan berkualitas tinggi dari versi 1.4.5:

#### 🆕 Ditambahkan (Added)

- **41 Paket Ikon Toolbar Baru (Total 69 Koleksi Bawaan Multi-Resolusi)**:
  - Melipatgandakan koleksi ikon dari 28 paket di v1.4.5 menjadi 69 paket bawaan lengkap (16x16, 20x20, 24x24, 32x32, 48x48, 64x64):
    - 11 Paket Ikon Tematik: `royal_blue`, `notepad_pro`, `pastel`, `fluent_modern`, `macos_bigsur_modern`, `dark_neon_pro`, `macos_glass`, `modern_flat_colorful`, `glossy_3d_skeuomorphic`, `retro_8bit_pixel`, `sketchy_doodle`.
    - 30 Paket Ikon Modern: `01-macos-big-sur`, `02-windows-11-fluent`, `03-arc-browser-glow`, `04-nordic-frost-minimal`, `05-dracula-cyber-neon`, `06-catppuccin-macchiato`, `07-tokyo-night-storm`, `08-synthwave-80s`, `09-monokai-pro-vivid`, `10-solarized-accent`, `11-retro-commodore-64`, `12-retro-win95-classic`, `13-matrix-phosphor-green`, `14-gameboy-nostalgia`, `15-pixel-dungeon-rpg`, `16-claymorphism-3d`, `17-skeuomorphic-leather-brass`, `18-neu-brutalism-bold`, `19-isometric-voxel-3d`, `20-origami-paper-fold`, `21-cyberpunk-2077-yellow`, `22-lofi-aesthetic-grain`, `23-vaporwave-pastel-sunset`, `24-astronomy-deep-space`, `25-botanical-nature-green`, `26-blueprint-schematic`, `27-chalkboard-handdrawn`, `28-gouache-art-paint`, `29-stained-glass-mosaic`, `30-swiss-minimal-3d`.
  - Mengusung standar Notepad++ Classic: tanpa bayangan lantai, tanpa halo abu-abu, dan tanpa garis timbul kasar, dengan margin 18% agar tidak terpotong di layar Retina.
  - Invarian Toolbar Gelap Permanen (`#21252b`) di seluruh mode dan tema.
- **Fitur Baru Menu Konteks Editor**:
  - Menu **Tempel & Cocokkan Format (Paste & Match Style)** (`Cmd+Alt+Shift+V` / `Ctrl+Shift+V`): menempel teks tanpa format bawaan dan menyesuaikan indentasi editor.
  - Menu **Cari di Google (Search on Google)** (`Cmd+Alt+G` / `Ctrl+Alt+G`): membuka browser untuk mencari teks terpilih atau kata di kursor secara langsung.
  - Menu konversi huruf langsung: **HURUF BESAR (UPPERCASE)** dan **huruf kecil (lowercase)** tanpa submenu bertingkat.
- **Opsi Baru Preferensi Umum (General Preferences)**:
  - Opsi sakelar Deteksi Otomatis Enkoding Karakter (`enableEncodingAutoDetection`).
  - Opsi sakelar Dialog Konfirmasi Simpan Semua (`enableSaveAllConfirmation`).
- **Perombakan Pewarnaan Sintaksis WCAG 2.1**:
  - Garansi matematis kontras rasio minimal 4.0:1 pada seluruh 70+ tema editor.
  - Lencana Emas (#FFD700) untuk penanda penting TODO, FIXME, BUG, HACK, NOTE.
  - Warna kuning amber hangat untuk urutan karakter escape string (\n, \t, \xHH).
  - Kotak indikator penanda kemunculan kata kunci tersinkronisasi dinamis dengan tema aktif.
- **Perombakan Total Engine & Live Preview Markdown**:
  - Riset mendalam dan integrasi praktik terbaik dari markedjs, markdown-it, stackedit, editor.md, milkdown, dan GitHub Flavored Markdown (GFM).
  - Konsolidasi dan deduplikasi mesin render callout ke MarkdownPreviewEnhancer::enhanceCallouts, menyingkirkan kode ganda lintas dock dan tab.
  - Implementasi Admonition / Callout resmi GitHub ([!NOTE], [!TIP], [!IMPORTANT], [!WARNING], [!CAUTION]) dengan ikon visual kontras tinggi, latar bernuansa lembut, dan batas aksen warna pada mode terang dan gelap.
  - Penambahan generator Daftar Isi interaktif ([TOC] / {:toc}) berjenjang dengan penautan otomatis ke slug heading dokumen.
  - Penambahan slug anchor otomatis pada tag heading (<h1 id="...">) untuk navigasi loncat dan tautan internal.
  - Penambahan konversi emoji shortcode (seperti :rocket:, :sparkles:, :white_check_mark:, :fire:, :star:, :memo:, :100:, dll.) dengan proteksi blok kode.
  - Penambahan chip pintasan keyboard [[Key]] -> <kbd>Key</kbd>.
  - Penyelarasan fungsi copyHtml(), openInBrowser(), dan DocumentExportManager::markdownToHtml agar hasil ekspor dan salinan HTML memuat seluruh rumus math, diagram mermaid, daftar tugas, catatan kaki, dan callout secara utuh.
  - Perbaikan database kompilasi (compile_commands.json) dengan sinkronisasi 685 header, menuntaskan 945+ pesan error IDE linter dan peringatan SonarLint.

#### 🔧 Diubah & Ditingkatkan (Changed & Improved)

- **Standar Pengemasan macOS DMG 30MB–40MB**:
  - Kalibrasi ukuran DMG rilis ke 38MB–39MB dengan mempertahankan pustaka universal Qt dan plugin format gambar standar (libqjpeg, libqgif, libqwebp).
  - Menggunakan format native hdiutil dengan preset tata letak .DS_Store (680x440), background retina, dan pengujian integritas checksum CRC32.
- **Pembersihan Menu Konteks**:
  - Menghapus opsi Run dan Bash encode/decode dari menu klik kanan editor agar lebih ringkas dan fokus.
- **Modernisasi Tampilan Tab Split & Arsitektur Zero Theme Clash**:
  - Menghilangkan gradien gelap metalik dan batas jingga/peach peninggalan lawas dengan mengaktifkan cds::CDockManager::DisableStylesheet, true.
  - Styling tab split sepenuhnya dinamis mengikuti palet tema aktif melalui ThemeManager.
- **UX Auto-Completion & Harmonisasi Tema**:
  - Menonaktifkan auto-completion secara default (autoCompletion = false) untuk mencegah popup kandidat yang mengganggu.
  - Mengganti penamaan tema bawaan menjadi sparkNotepad ("SparkNotepad Default") dengan kompatibilitas mundur.
- **Engine Pembaruan Multi-Build updates.json & Force-Update Komprehensif**:
  - Memperbarui updates.json ke v1.4.6 dengan dukungan matriks rilis lengkap dan kebijakan pembaruan wajib.
- **Audit Kualitas Kode 14 Pilar & Audit Linter**:
  - 100% lulus bersih pada cppcheck (171 berkas, 0 kesalahan), clangd, clang-tidy, dan ctest.
  - Penyesuaian aturan SonarLint pada parameter lambda dan pointer-to-const.
