## 1. Executive Summary: Changes in v1.4.7

SparkNotePad v1.4.7 delivers core engine upgrades, cross-platform workspace mobility, POSIX script diagnostics, large-file encoding resilience, enhanced navigation ergonomics, and comprehensive 2025–2026 CVE security hardening:

1. Core Engine Upgrade to Scintilla 5.6.9 & Lexilla 5.5.5:
   - Synchronized Scintilla to v5.6.9 (Unicode 17 character categories, 40-byte lexeme cache, line-start layout bypass accelerating rendering, change history undo crash fix, and restored XPM autocompletion/marker colors).
   - Synchronized Lexilla to v5.5.5 (Markdown YAML/TOML/JSON front-matter styling [#59], HTML/JS nested template literals [#290], regex '/' in character classes [#377], non-ASCII JS identifiers [#371], PHP $$variable styling [#2208], and all 12 memory safety/OOB/hang fixes [#388]).
   - Applied the 4 official post-5.5.1 bug-fix patches to embedded Lua 5.5.1 (luaO_applyparam negative shift guard, lvm.c NaN for-loop fix, lcode.c -0.0 - 0 folding prevention, and lcorolib.c error message preservation during unwind).

2. System Transfer & Portable Workspace Bundle (SparkTransferManager & TransferBundleDialog):
   - Implemented File -> System Transfer -> Export / Import Workspace Bundle (.sparkbundle) enabling seamless migration of preferences, custom themes (QSS), macros, sessions, and Lua/Python user scripts across macOS, FreeBSD, and Linux.
   - Hardened with Zip-Slip path sanitization (CVE-2026-57233), path traversal rejection (CVE-2026-52886), in-memory SHA-256 HMAC integrity verification (CVE-2026-52885), and optional AES-256-CBC encryption.

3. POSIX Shell Inspector & Touch Utility (PosixFileInspector):
   - Added shebang dialect detection for Bash, Zsh, Dash, Ksh, POSIX sh, Python, Lua, and FreeBSD rc.d scripts.
   - Added octal (0755/0600) and symbolic (rwxr-xr-x/rw-------) permission formatters.
   - Integrated FieldPosixPerms badge in EditorInfoStatusBar with one-click executable bit toggle (chmod +x).
   - Added File Permissions submenu in MainWindow with "Toggle Executable Bit (chmod +x)" and "Enforce Owner-Only Private Mode (chmod 0600)".
   - Added precision file touch utility using POSIX utimes.

4. Stateless 3-Point EncodingDetector & Atomic Large-File Save Guard:
   - Implemented 3-point sampling (header 16KB, midpoint 16KB, tail 16KB) for robust large-file character set detection via uchardet.
   - Added explicit UTF-32 LE/BE BOM support (\xFF\xFE\x00\x00 and \x00\x00\xFE\xFF).
   - Hardened ScintillaNext::writeToDisk with atomic saving via private sibling temporary files (.filename.sparktmp), 0600 permissions, fsync(), original permission mode preservation, and atomic POSIX rename().

5. Multi-Mode GotoDialog & Project Tree Safe Rename Preview:
   - Replaced legacy modal input with multi-mode GotoDialog supporting Visual Line:Column, Character Offset (Line:-Col), and Document Byte Offset with real-time target position calculation.
   - Implemented safe rename dialog in FolderAsWorkspaceDock with path traversal defense, collision detection, and dry-run preview before disk modification.

6. Comprehensive 2025–2026 CVE Security Hardening:
   - Automated test verification against CVE-2026-42214, CVE-2026-48778, CVE-2026-52885, CVE-2026-52886, CVE-2026-57233, CVE-2026-54758, and CVE-2026-77605.

7. About Dialog Credits & Markdown Preview Color Polish:
   - Resolved %2 placeholder index bug in AboutDialog Credits tab that erroneously rendered raw color hex #0550ae as a heading title instead of applying it as CSS color to <h3>.
   - Removed hardcoded #0550ae on inline/block math equations to naturally inherit active theme text color.

8. 14-Pillar Code Quality & SonarLint/Clang-Tidy Remediation:
   - Resolved clang-tidy braces around statements, virtual override visibility, and move semantics across EditorInfoStatusBar, QuickFindWidget, StatusLabel, and FocusWatcher with 0 linter errors.

9. Standard Lightweight macOS DMG Packaging (30MB–40MB Standard):
   - Packaged and verified build/SparkNotePad-v1.4.7-x64.dmg (40M, 40,652,861 bytes) with custom background, layout preset .DS_Store (680x440), and verified CRC32 checksum.

## 2. Archive Summary: Release v1.4.6

SparkNotePad v1.4.6 delivers major enhancements across visual customization, editor context menu ergonomics, general preferences options, WCAG 2.1 contrast mathematical safety for syntax highlighting, and canonical 30MB–40MB macOS DMG packaging:

1. Toolbar Icon Packs Expansion (69 Built-in Suites Total):
   - Expanded from the 28 icon packs in v1.4.5 by adding 41 new multi-resolution icon suites across all resolutions (16x16, 20x20, 24x24, 32x32, 48x48, 64x64).
   - Clean Notepad++ Classic standard: completely eradicated floor drop shadows, halos, gray background tiles, and edge clipping across all packs, with 18% breathing margins preventing clipping on Retina displays.
   - Permanent Dark Toolbar Invariant: `#mainToolBar` permanently locked to `#21252b` across all themes and appearance modes to guarantee icon contrast.

2. Context Menu Ergonomics Overhaul:
   - Added "Paste & Match Style" (pasteAndMatchStyle, Cmd+Alt+Shift+V / Ctrl+Shift+V) to strip foreign formatting and match current indentation level.
   - Added "Search on Google" (searchOnGoogle, Cmd+Alt+G / Ctrl+Alt+G) to instantly query selected text or word under cursor in system browser.
   - Streamlined case conversion to direct UPPERCASE and lowercase actions, eliminating cluttered run/bash options.

3. General Preferences Additions:
   - Added option to Enable / Disable Character Encoding Auto-detection (enableEncodingAutoDetection) in Preferences > General.
   - Added option to Enable / Disable Save All Confirmation dialog (enableSaveAllConfirmation) in Preferences > General.

4. Syntax Highlighting & Theme Engine Mathematical Overhaul (WCAG 2.1):
   - Integrated WCAG 2.1 relative luminance and contrast calculations (0.2126*R + 0.7152*G + 0.0722*B), guaranteeing minimum 4.0:1 contrast ratio on primary text across all 70+ themes.
   - Semantic styling tailored to language families (C/C++, Python, Web/HTML/JS/CSS, Markdown progressive H1-H6, SQL, Shell, YAML, etc.).
   - High-visibility Gold Badges (#FFD700) for critical comment markers (TODO, FIXME, BUG, HACK, NOTE).
   - Warm golden amber for string escape sequences (\n, \t, \xHH).
   - Theme-synchronized rounded border box indicator for SmartHighlighter word occurrences.

5. Standard Lightweight macOS DMG Packaging (30MB–40MB Standard):
   - Calibrated release DMG packaging strictly between 30MB and 40MB (38MB–39MB) preserving universal Qt libraries and standard image format plugins.
